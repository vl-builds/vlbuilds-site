## Tarefa 1 — C5: Converter imagens para WebP (LCP fix — Parte 1)

**Impacto:** LCP 53.7s → estimado <4s. As 12 PNGs dos service cards são ~5MB cada e são a causa principal.

**Files:**
- Criar: `scripts/convert-webp.mjs`
- Criar: `public/services/01-dark.webp` … `06-light.webp` (output do script)

- [ ] **Step 1: Instalar sharp como devDependency**

```powershell

```

- [ ] **Step 2: Criar o script de conversão**

Criar `scripts/convert-webp.mjs`:

```js
import sharp from 'sharp';
import { readdirSync, existsSync, mkdirSync } from 'fs';
import { join, basename } from 'path';

const dir = 'public/services';
const files = readdirSync(dir).filter(f => f.endsWith('.png'));

console.log(`Converting ${files.length} PNGs to WebP...`);
for (const file of files) {
  const src  = join(dir, file);
  const dest = join(dir, basename(file, '.png') + '.webp');
  await sharp(src).webp({ quality: 82 }).toFile(dest);
  const srcKB  = Math.round((await sharp(src).metadata()).size  / 1024 || 0);
  const stat   = await import('fs').then(m => m.promises.stat(dest));
  const destKB = Math.round(stat.size / 1024);
  console.log(`  ✓ ${file} → ${basename(dest)} (${destKB}KB)`);
}
console.log('Done.');
```

- [ ] **Step 3: Correr o script**

```powershell

```

Resultado esperado: 12 ficheiros `XX-dark.webp` e `XX-light.webp` em `public/services/`. Cada um deve ser <300KB.
